# SushiRoll — сайт доставки суши

Одностраничный сайт-визитка для доставки суши. Без фреймворков и сборщиков — чистый HTML, CSS и ванильный JavaScript.

## Возможности

- Адаптивная вёрстка (десктоп / планшет / мобильный)
- Промо-слайдер с автопрокруткой и точками навигации
- Плавная прокрутка с подсветкой активного пункта меню
- Липкая шапка с эффектом размытия при прокрутке
- Мобильное меню (бургер) с закрытием по Esc / клику вне меню
- Кнопка «наверх» и прелоадер
- Поддержка `prefers-reduced-motion`

## Структура

```
sushi-website/
├── index.html       # разметка страницы
├── css/
│   └── main.css     # стили (дизайн-система на CSS-переменных)
├── js/
│   └── main.js      # вся логика (без jQuery)
└── images/          # готовые изображения товаров и баннеров
```

## Запуск

Просто открой `index.html` в браузере — никаких зависимостей не требуется.

## Как редактировать

- **Товары** — разметка в `index.html`, каждая карточка — блок `<article class="dish">`.
- **Цены и имена** — меняются прямо в HTML.
- **Цвета** — CSS-переменные в начале `css/main.css`.
- **Телефоны** — ссылки `tel:` в шапке карточек заказа и в блоке «Доставка».

> Кнопки «Заказать» ведут на звонок по телефону (временно, пока нет корзины).
